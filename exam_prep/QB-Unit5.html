Q1. What is a user-defined function? Why is it necessary to use user-defined functions in a program?

Answer:

User-defined function: A function created by the programmer to perform a specific task.

Necessity:

  • Promotes modular programming
  • Enhances code reusability
  • Simplifies debugging and testing
  • Improves readability and maintainability

Q2. What are the advantages of using user-defined functions in programming?

Answer:
  • Reusability: Write once, use multiple times
  • Modularity: Break down complex problems into smaller tasks
  • Ease of maintenance: Changes in one function do not affect others
  • Abstraction: Hide implementation details
  • Collaboration: Different programmers can work on different functions

Q3. Create a program that uses multiple user-defined functions to perform different tasks.

Answer: 
C#include <stdio.h>

void greet() {
    printf("Hello! ");
}

int add(int a, int b) {
    return a + b;
}

void display(int result) {
    printf("Result: %d\n", result);
}

int main() {
    greet();
    
    int sum = add(5, 3);
    
    display(sum);
    
    return 0;
}

Q4. What are the key elements of a user-defined function in C?

Answer:
  • Return type - Data type of returned value
  • Function name - Identifier for the function
  • Parameter list (optional) - Input values
  • Function body - Executable statements
  • Return statement (optional) - Value to return

Q6. What is a function return type? How is it used in function definitions?

Answer:

The return type specifies the type of value returned by the function. It is declared before the function name.

Example:

Cint getAge() {
    return 25;
}

If no value is returned, use void.

Q12. Explain the concept of functions that return multiple values. How can this be achieved in C?

Answer:

C does not directly support returning multiple values. However, it can be achieved using:

  • Pointers
  • Structures
  • Arrays

Example using pointers:

Cvoid getTwoValues(int *a, int *b) {
    *a = 10;
    *b = 20;
}

Q13. What is function nesting? Give an example of a program where one function calls another function.

Answer:

Function nesting is when one function calls another within its body.

C#include <stdio.h>

void inner() {
    printf("Inside inner function.\n");
}

void outer() {
    printf("Inside outer function.\n");
    inner();
}

int main() {
    outer();
    
    return 0;
}

Q14. What is recursion in C? Write a recursive function to find the factorial of a number.

Answer:

Recursion is a process where a function calls itself.

C#include <stdio.h>

int factorial(int n) {
    if (n == 0 || n == 1)
        return 1;
    else
        return n * factorial(n - 1);
}

int main() {
    printf("Factorial of 5: %d\n", factorial(5));
    
    return 0;
}

Q15. Explain the process of function declaration. How is it different from a function definition?

Answer:

Function Declaration: Informs the compiler about the function's name, return type, and parameters.

Example: int add(int, int);

Function Definition: Contains the actual implementation of the function.

Example:

Cint add(int a, int b) {
    return a + b;
}

Q16. What is a structure in C? Why do we use structures in programming?

Answer:

A structure is a user-defined data type that groups related variables of different data types.

Why use structures?

  • Organize complex data
  • Represent real-world entities (e.g., Student, Employee)
  • Pass grouped data to functions easily

Q17. How do you declare a structure type in C? Provide an example.

Answer: 
Cstruct Student {
    int rollNo;
    char name[50];
    float marks;
};

Q18. How do you reference individual members of a structure? Illustrate with an example.

Answer:

Use the dot (.) operator.

Cstruct Student s1;

s1.rollNo = 1;
strcpy(s1.name, "John");
s1.marks = 85.5;

Q19. What is the syntax for referencing an entire structure? Provide an example.

Answer:

You can assign one structure variable to another of the same type.

Cstruct Student s1 = {1, "John", 85.5};
struct Student s2;

s2 = s1;  // Entire structure copied

Q20. How do you initialize a structure in C? Write an example program that initializes a structure.

Answer: 
C#include <stdio.h>

struct Student {
    int rollNo;
    char name[50];
    float marks;
};

int main() {
    struct Student s1 = {101, "Alice", 92.5};
    
    printf("Roll No: %d\n", s1.rollNo);
    printf("Name: %s\n", s1.name);
    printf("Marks: %.2f\n", s1.marks);
    
    return 0;
}
