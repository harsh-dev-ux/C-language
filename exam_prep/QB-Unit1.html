Q1. What is an algorithm? Explain its characteristics.

Answer:

Algorithm: A step-by-step procedure to solve a problem or perform a task.

Characteristics:

Characteristic Description
InputZero or more inputs
OutputAt least one output
DefinitenessEach step is clear and unambiguous
FinitenessMust terminate after finite steps
EffectivenessEach step must be basic and feasible

Q3. What is a flowchart? List its advantages and disadvantages.

Answer:

Flowchart: A graphical representation of an algorithm using standard symbols.

Advantages:

  • Easy to understand and communicate
  • Helps in debugging and documentation
  • Provides visual clarity of program flow
  • Useful for training new programmers

Disadvantages:

  • Time-consuming for complex programs
  • Difficult to modify once drawn
  • No standard rules for level of detail
  • Can become confusing for large programs

Q6. Explain the basic structure of a C program with an example.

Answer: 
C/* Documentation Section */
// Program to add two numbers

/* Preprocessor Directives */
#include <stdio.h>

/* Global Declarations */
int result;

/* Main Function */
int main() {
    
    /* Local Declarations */
    int a = 10;
    int b = 20;
    
    /* Executable Statements */
    result = a + b;
    
    printf("Sum = %d\n", result);
    
    return 0;
}

Sections:

  • Documentation: Comments describing program
  • Preprocessor: Include files and macros
  • Global Declarations: Variables accessible everywhere
  • Main Function: Program execution starts here
  • Local Declarations: Variables inside functions
  • Executable Statements: Actual program logic

Q11. Explain printf() and scanf() functions with examples.

Answer:

printf() - Output Function:

Used to display output on the screen.

Syntaxprintf("format string", arguments);

scanf() - Input Function:

Used to read input from the keyboard.

Syntaxscanf("format string", &variable);

Example Program:

C#include <stdio.h>

int main() {
    int age;
    char name[50];
    
    // Output
    printf("Enter your name: ");
    
    // Input string
    scanf("%s", name);
    
    printf("Enter your age: ");
    
    // Input integer
    scanf("%d", &age);
    
    // Output with formatting
    printf("Hello %s, you are %d years old.\n", name, age);
    
    return 0;
}

Q13. Write a C program to swap two numbers without using a third variable.

Answer: 
C#include <stdio.h>

int main() {
    int a, b;
    
    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);
    
    printf("Before swap: a = %d, b = %d\n", a, b);
    
    // Swapping without third variable
    a = a + b;
    b = a - b;
    a = a - b;
    
    printf("After swap: a = %d, b = %d\n", a, b);
    
    return 0;
}

Q14. What are storage classes in C? Explain each with examples.

Answer:

Storage Classes: Define the scope, lifetime, and visibility of variables.

Storage Class Scope Lifetime Default Value
autoLocalWithin blockGarbage
registerLocalWithin blockGarbage
staticLocalEntire program0
externGlobalEntire program0

Example:

C#include <stdio.h>

extern int globalVar;  // External variable

void counter() {
    static int count = 0;  // Static - retains value
    count++;
    printf("Count = %d\n", count);
}

int main() {
    auto int x = 10;       // Auto - default for local
    register int i;        // Register - stored in CPU register
    
    counter();  // Output: Count = 1
    counter();  // Output: Count = 2
    counter();  // Output: Count = 3
    
    return 0;
}

Q15. Draw a flowchart to find the largest of three numbers.

Answer:
flowchart TD A([START]) --> B[/Read A, B, C/] B --> C{A > B?} C -->|Yes| D{A > C?} C -->|No| E{B > C?} D -->|Yes| F[A is Largest] D -->|No| G[C is Largest] E -->|Yes| H[B is Largest] E -->|No| I[C is Largest] F --> J[/Display Largest/] G --> J H --> J I --> J J --> K([STOP])

C Program:

C#include <stdio.h>

int main() {
    int a, b, c, largest;
    
    printf("Enter three numbers: ");
    scanf("%d %d %d", &a, &b, &c);
    
    if (a > b) {
        if (a > c)
            largest = a;
        else
            largest = c;
    } 
    else {
        if (b > c)
            largest = b;
        else
            largest = c;
    }
    
    printf("Largest number is: %d\n", largest);
    
    return 0;
}
