Q1. What is an Array in C Programming?

Answer:

Array: A collection of similar data items stored in contiguous memory locations.

Key Characteristics:

  • Homogeneous elements: All elements same data type
  • Fixed size: Size defined at declaration
  • Contiguous memory: Elements stored consecutively
  • Index-based access: Starts from 0
  • Random access: Direct access to any element

Declaration Syntax:

Syntaxdata_type array_name[size];

Example:

Cint marks[5];        // Array of 5 integers
float prices[10];    // Array of 10 floats
char name[20];       // Array of 20 characters

Memory Representation:

MemoryArray: int arr[5] = {10, 20, 30, 40, 50}

Index:   0    1    2    3    4
Value:  10   20   30   40   50
Address:1000 1004 1008 1012 1016 (4 bytes each)

Q2. How to create an Array?

Answer:

Steps to create an array:

  1. Declaration: Specify type, name, and size
  2. Initialization: Assign initial values
  3. Access: Use index to access/modify elements

Examples:

C// Method 1: Declare and initialize later
int numbers[5];
numbers[0] = 10;
numbers[1] = 20;

// Method 2: Declare with initialization
int arr1[5] = {1, 2, 3, 4, 5};  // All elements
int arr2[5] = {1, 2, 3};        // Partial (rest = 0)
int arr3[] = {1, 2, 3, 4, 5};   // Size auto-calculated

// Method 3: Character array
char str1[6] = {'H', 'e', 'l', 'l', 'o', '\0'};
char str2[6] = "Hello";  // '\0' added automatically

// Method 4: 2D array
int matrix[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

Q3. What are the properties of an array?

Answer:

Properties of Arrays:

  • Fixed Size: Cannot change at runtime
  • Homogeneous Elements: Same data type
  • Contiguous Memory: Sequential storage
  • Index-based Access: 0 to size-1
  • Random Access: O(1) access time
  • No Bounds Checking: C doesn't check boundaries
  • Name = Base Address: Array name points to first element

Example:

C#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    
    // Size of array
    printf("Total size: %lu bytes\n", sizeof(arr));
    
    // Number of elements
    printf("Elements: %lu\n", sizeof(arr) / sizeof(arr[0]));
    
    // Base address
    printf("Base address: %p\n", arr);
    
    // Element access
    printf("Element at index 2: %d\n", arr[2]);
    
    return 0;
}

Q4. Advantages and disadvantages of Array?

Answer:

Advantages:

  • Random Access: O(1) time complexity
  • Memory Efficient: No extra overhead
  • Cache Friendly: Contiguous storage
  • Easy Implementation: Simple syntax
  • Multi-dimensional: Support for matrices

Disadvantages:

  • Fixed Size: Cannot resize
  • Memory Wastage: If size overestimated
  • Insertion/Deletion: Expensive (shifting required)
  • Homogeneous: Only one data type
  • No Bounds Checking: Buffer overflow risk

Q5. Can we change the size of an array at run time?

Answer:

No, we cannot change the size of a static array at runtime in C.

Alternatives for dynamic sizing:

1. Dynamic Memory Allocation:

C#include <stdio.h>
#include <stdlib.h>

int main() {
    int *arr;
    int size = 5;
    
    // Allocate memory
    arr = (int*) malloc(size * sizeof(int));
    
    // Use array...
    
    // Resize to 10 elements
    size = 10;
    arr = (int*) realloc(arr, size * sizeof(int));
    
    // Free memory when done
    free(arr);
    
    return 0;
}

2. Variable Length Array (VLA) - C99:

Cint n;

printf("Enter size: ");
scanf("%d", &n);

int arr[n];  // Size determined at runtime

Q7-8. What is a two-dimensional array? Why do we need multidimensional arrays?

Answer:

Two-dimensional array: Array of arrays, representing rows and columns.

Declaration:

Syntaxdata_type array_name[rows][columns];

Why Multidimensional Arrays:

  • Represent matrices and tables
  • Game boards (chess, tic-tac-toe)
  • Image processing (pixels)
  • Scientific computing
  • Spreadsheet data

Example:

C#include <stdio.h>

int main() {
    int matrix[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };
    
    int i, j;
    
    printf("Matrix:\n");
    
    for (i = 0; i < 3; i++) {
        for (j = 0; j < 3; j++) {
            printf("%d\t", matrix[i][j]);
        }
        printf("\n");
    }
    
    printf("\nElement at [1][2]: %d\n", matrix[1][2]);
    
    return 0;
}

Q10. Write a program to insert an element at a specific position in array.

Answer: 
C#include <stdio.h>

int main() {
    int arr[100];
    int n, pos, element, i;
    
    printf("Enter size of array: ");
    scanf("%d", &n);
    
    printf("Enter %d elements:\n", n);
    for (i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }
    
    printf("Enter element to insert: ");
    scanf("%d", &element);
    
    printf("Enter position (1 to %d): ", n + 1);
    scanf("%d", &pos);
    
    // Shift elements to right
    for (i = n; i >= pos; i--) {
        arr[i] = arr[i - 1];
    }
    
    // Insert element
    arr[pos - 1] = element;
    n++;
    
    printf("\nArray after insertion:\n");
    for (i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    
    return 0;
}

Q16. How to compare strings in C?

Answer:

strcmp() function:

  • Returns 0 if strings are equal
  • Returns <0 if str1 < str2
  • Returns >0 if str1 > str2

Example:

C#include <stdio.h>
#include <string.h>

int main() {
    char str1[] = "apple";
    char str2[] = "banana";
    char str3[] = "apple";
    
    int result;
    
    // Compare str1 and str2
    result = strcmp(str1, str2);
    
    if (result == 0) {
        printf("%s and %s are equal\n", str1, str2);
    } 
    else if (result < 0) {
        printf("'%s' comes before '%s'\n", str1, str2);
    } 
    else {
        printf("'%s' comes after '%s'\n", str1, str2);
    }
    
    // Compare str1 and str3
    if (strcmp(str1, str3) == 0) {
        printf("%s and %s are equal\n", str1, str3);
    }
    
    return 0;
}

Q17. Program to reverse words in a given string.

Answer: 
C#include <stdio.h>
#include <string.h>

// Function to reverse string portion
void reverse(char str[], int start, int end) {
    char temp;
    
    while (start < end) {
        temp = str[start];
        str[start] = str[end];
        str[end] = temp;
        start++;
        end--;
    }
}

// Function to reverse words
void reverseWords(char str[]) {
    int len = strlen(str);
    int start = 0;
    int i;
    
    // Step 1: Reverse entire string
    reverse(str, 0, len - 1);
    
    // Step 2: Reverse each word
    for (i = 0; i <= len; i++) {
        if (str[i] == ' ' || str[i] == '\0') {
            reverse(str, start, i - 1);
            start = i + 1;
        }
    }
}

int main() {
    char str[100] = "Hello World Program";
    
    printf("Original: %s\n", str);
    
    reverseWords(str);
    
    printf("Reversed: %s\n", str);
    // Output: Program World Hello
    
    return 0;
}
