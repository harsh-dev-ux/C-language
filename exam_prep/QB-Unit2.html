Q5. How do relational operators interact with if-else statements in C?

Answer:

Relational operators create conditions for if-else statements.

Interaction:

  • Relational operators return 1 (true) or 0 (false)
  • if-else uses these boolean results
  • If condition is true (1), if-block executes
  • If condition is false (0), else-block executes

Example:

C#include <stdio.h>

int main() {
    int age = 20;
    
    // Relational operator in if condition
    if (age >= 18) {  // Returns 1 (true)
        printf("Eligible to vote.\n");
    } 
    else {  // Would execute if false
        printf("Not eligible to vote.\n");
    }
    
    return 0;
}

Q9-10. How do compound assignment operators work? Write a program demonstrating them.

Answer:

Compound Assignment Operators: Perform operation and assignment in one step.

Working:

  • x += y is equivalent to x = x + y
  • x -= y is equivalent to x = x - y
  • x *= y is equivalent to x = x * y
  • x /= y is equivalent to x = x / y
  • x %= y is equivalent to x = x % y

Program:

C#include <stdio.h>

int main() {
    int a = 10, b = 3;
    
    printf("Initial values: a = %d, b = %d\n\n", a, b);
    
    // Using assignment operators
    a += b;  // a = a + b
    printf("After a += b: a = %d\n", a);
    
    a -= b;  // a = a - b
    printf("After a -= b: a = %d\n", a);
    
    a *= b;  // a = a * b
    printf("After a *= b: a = %d\n", a);
    
    a /= b;  // a = a / b
    printf("After a /= b: a = %d\n", a);
    
    a %= b;  // a = a % b
    printf("After a %%= b: a = %d\n", a);
    
    return 0;
}

Q11. What are the increment and decrement operators in C? Provide examples.

Answer:

Increment/Decrement Operators:

  • ++ Increment: Increases value by 1
  • -- Decrement: Decreases value by 1

Types:

TypeSyntaxDescription
Pre-increment++xIncrement first, then use
Post-incrementx++Use first, then increment
Pre-decrement--xDecrement first, then use
Post-decrementx--Use first, then decrement

Examples:

Cint x = 5;

// Post-increment
printf("%d\n", x++);  // Prints 5, then x becomes 6
printf("%d\n", x);    // Prints 6

// Pre-increment
printf("%d\n", ++x);  // x becomes 7, then prints 7

// Post-decrement
printf("%d\n", x--);  // Prints 7, then x becomes 6

// Pre-decrement
printf("%d\n", --x);  // x becomes 5, then prints 5

Q13-14. What is the conditional (ternary) operator? Write a program to find the largest of two numbers.

Answer:

Conditional (Ternary) Operator: ? :

  • Compact form of if-else
  • Takes three operands

Syntax:

Syntaxcondition ? expression1 : expression2;

// If condition is true → expression1 executes
// If condition is false → expression2 executes

Program to find largest of two numbers:

C#include <stdio.h>

int main() {
    int num1, num2, largest;
    
    // Input two numbers
    printf("Enter first number: ");
    scanf("%d", &num1);
    
    printf("Enter second number: ");
    scanf("%d", &num2);
    
    // Using conditional operator
    largest = (num1 > num2) ? num1 : num2;
    
    printf("The largest number is: %d\n", largest);
    
    return 0;
}

Q16-19. Special Operators: Bitwise Shift, sizeof, and Comma Operators

Answer:

Bitwise Shift Operators:

  • << Left shift: x << n = x * 2^n
  • >> Right shift: x >> n = x / 2^n

sizeof() Operator:

Returns size of data type/variable in bytes.

Comma Operator (,):

Evaluates multiple expressions, returns value of last expression.

C#include <stdio.h>

int main() {
    // sizeof operator
    printf("Size of int: %lu bytes\n", sizeof(int));
    printf("Size of float: %lu bytes\n", sizeof(float));
    printf("Size of char: %lu bytes\n", sizeof(char));
    printf("Size of double: %lu bytes\n", sizeof(double));
    
    // Shift operators
    int x = 5;  // Binary: 00000101
    printf("5 << 1 = %d\n", x << 1);  // 10 (5 * 2)
    printf("5 >> 1 = %d\n", x >> 1);  // 2  (5 / 2)
    
    // Comma operator
    int a, b, c;
    a = 5, b = 10, c = 15;
    
    int result = (a = 5, b = 10, a + b);  // result = 15
    printf("Result: %d\n", result);
    
    return 0;
}

Q20-23. Arithmetic Expressions and Operator Precedence

Answer:

Arithmetic Expressions:

Combinations of operands and operators that evaluate to a numeric value.

C// Simple expressions
int a = 5 + 3;        // 8
int b = 10 - 4;       // 6
int c = 6 * 7;        // 42
float d = 15.0 / 4.0; // 3.75
int e = 17 % 5;       // 2

// Complex expressions
float result1 = (a + b) * c;
float result2 = a + b * c;  // Different due to precedence

Order of Evaluation for a + b * c - d / e:

StepsExpression: a + b * c - d / e

Step 1: b * c  (multiplication has highest precedence)
Step 2: d / e  (division same as multiplication, left to right)
Step 3: a + (result of b*c)
Step 4: (result) - (result of d/e)

Equivalent to: a + (b * c) - (d / e)

Operator Precedence (Highest to Lowest):

PrecedenceOperatorAssociativity
1()Left to Right
2++ -- (postfix)Left to Right
3++ -- (prefix)Right to Left
4* / %Left to Right
5+ -Left to Right
6=Right to Left
