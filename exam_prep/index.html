What is Algorithm?

An algorithm is a step-by-step procedure to solve a problem. It must be finite, precise, and effective.

Characteristics of Algorithm

CharacteristicDescription
FinitenessMust terminate after a finite number of steps
DefinitenessEach step must be precisely defined
EffectivenessEach step must be executable in finite time
InputZero or more inputs required
OutputOne or more outputs produced
GeneralityMust work for all valid inputs

Algorithm Examples

1. Add Two Numbers

AlgorithmStep 1: Start
Step 2: Declare variables num1, num2, sum
Step 3: Read num1 and num2
Step 4: sum = num1 + num2
Step 5: Display sum
Step 6: Stop

2. Check Even or Odd

AlgorithmStep 1: Start
Step 2: Declare variable n
Step 3: Read n
Step 4: IF n % 2 == 0 THEN print "Even"
Step 5: ELSE print "Odd"
Step 6: Stop

3. Find Largest of Three Numbers

AlgorithmStep 1: Start
Step 2: Declare a, b, c
Step 3: Read a, b, c
Step 4: IF a >= b AND a >= c THEN print a
Step 5: ELSE IF b >= a AND b >= c THEN print b
Step 6: ELSE print c
Step 7: Stop

4. Factorial of a Number

AlgorithmStep 1: Start
Step 2: Declare n, i, fact=1
Step 3: Read n
Step 4: FOR i = 1 to n DO fact = fact * i
Step 5: Display fact
Step 6: Stop

Control Flow Overview

Control flow determines the order in which statements execute. C provides branching, looping, and jump statements.

graph TD A[Control Flow] --> B[Decision/Branching] A --> C[Looping] A --> D[Jump Statements] B --> B1[if] B --> B2[if-else] B --> B3[else-if ladder] B --> B4[nested if] B --> B5[switch] C --> C1[while] C --> C2[do-while] C --> C3[for] D --> D1[break] D --> D2[continue] D --> D3[goto]

Simple if Statement

Executes statements only when condition is true.

flowchart TD A([Start]) --> B{Condition?} B -->|True| C[Statement Block] C --> D[Statement-x] B -->|False| D D --> E([End])
Cint age = 20;
if (age >= 18) {
printf("Eligible to vote\n");
}
if (age < 18) {
printf("Not eligible\n");
}

if-else Statement

Executes one block if true, another if false.

flowchart TD A([Start]) --> B{Condition?} B -->|True| C[True Block] B -->|False| D[False Block] C --> E[Statement-x] D --> E E --> F([End])

switch Statement

Multi-way branching based on expression value.

Rules for switch:

  • Expression must be integer or character type
  • Case values must be constants (no variables)
  • break exits switch block
  • default is optional (handles unmatched cases)
  • Cases must be unique
flowchart TD A([Start]) --> B[Evaluate Expression] B --> C{Value1?} C -->|Yes| D[Block-1 + break] C -->|No| E{Value2?} E -->|Yes| F[Block-2 + break] E -->|No| G[Default Block] D --> H([End]) F --> H G --> H
Student Gradechar grade = 'B';
switch(grade) {
case 'A': printf("Outstanding!\n"); break;
case 'B': printf("Excellent!\n"); break;
case 'C': printf("Well Done\n"); break;
case 'D': printf("You passed\n"); break;
case 'F': printf("Better try again\n"); break;
default: printf("Invalid grade\n");
}
printf("Your grade is %c\n", grade);

while Loop (Entry-Controlled)

Condition checked first, may execute 0 times. Use when iterations are unknown.

flowchart TD A([Start]) --> B{Condition?} B -->|True| C[Loop Body] C --> B B -->|False| D([End])

while (n <= 10) {

printf("Sum = %d\n", sum); // 385
Reverse a Numberint reverse = 0, number = 12345;

printf("Reverse: %d\n", reverse); // 54321

do-while Loop (Exit-Controlled)

Executes at least once, condition checked after. Use when at least one execution is required.

flowchart TD A([Start]) --> B[Loop Body] B --> C{Condition?} C -->|True| B C -->|False| D([End])

Recursion

Function calling itself. Must have base case to stop recursion.

Factorial using Recursion

Cint factorial(int n) {
if (n == 0 || n == 1)
return 1; // Base case
else
return n * factorial(n - 1); // Recursive call
}

printf("%d", factorial(5)); // 120

Fibonacci using Recursion

Cint fib(int n) {
if (n <= 1) return n;
return fib(n-1) + fib(n-2);
}
